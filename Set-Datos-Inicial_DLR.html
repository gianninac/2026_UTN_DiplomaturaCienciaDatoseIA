Diagrama Lógico Relacional (DLR)

Descripción del conjunto de datos de partida y sus relaciones.

Pacientes
dni (PK) Entero (ID)
nombre Texto
apellido Texto
fecha_nacimiento Fecha
sexo Texto
Turnos
id_turno (PK) Entero (ID)
dni (FK) Entero
fecha Fecha
hora Hora
tratamiento Texto
profesional Texto
estado Texto
Motivo inasistencia
id_turno (PK/FK) Entero (ID)
motivo Texto
comentario Texto
Encuesta satisfacción
id_turno (PK/FK) Entero (ID)
satisfacción Entero
volvería Boolean
recomendaría Boolean

Cardinalidad y Reglas de Negocio

1:N

Pacientes a Turnos: Un paciente puede tener muchos turnos.

1:1

Turnos a Motivo: Un turno no concretado puede tener un motivo de inasistencia.

1:1

Turnos a Encuesta: Un turno concretado puede tener una encuesta de satisfacción.
